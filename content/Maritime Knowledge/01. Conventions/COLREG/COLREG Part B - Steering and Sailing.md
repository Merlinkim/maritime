# COLREG Part B - Steering and Sailing

> Note: This page is a study note, not a verbatim legal copy.
> 주의: 이 페이지는 학습용 정리이며 법령 원문 전체의 재배포본이 아니다.

Official source: USCG Navigation Rules / 72 COLREGS — https://www.navcen.uscg.gov/navigation-rules-amalgamated

## Purpose

Part B contains the main conduct rules for collision avoidance.

## Scope

Rules 4 to 19 cover conduct in any visibility, vessels in sight, and restricted visibility.

## Core Content

- Rule 5 requires proper lookout.
- Rule 6 requires safe speed.
- Rule 7 requires proper risk assessment.
- Rule 8 requires positive, timely, and seamanlike action.
- Rules 13 to 17 govern overtaking, head-on, crossing, give-way, and stand-on vessels.
- Rule 19 governs restricted visibility.

## Watch Points

- Part B is not a set of isolated rules; it is a decision sequence.
- Restricted visibility changes the logic because vessels may not be in sight.
- Standing-on is not passive; Rule 17 still requires judgment.

## Study Order

1. Start with Rules 5-8.
2. Then learn traffic schemes and narrow channels.
3. Then master overtaking/head-on/crossing.
4. Finish with restricted visibility.
