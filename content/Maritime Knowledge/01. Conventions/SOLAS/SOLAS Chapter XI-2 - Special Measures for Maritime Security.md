# SOLAS Chapter XI-2 - Special Measures for Maritime Security

## Purpose

Chapter XI-2 makes the ISPS Code mandatory and sets the maritime security framework.

## Scope

It applies to ship and port facility security arrangements.

## Core Content

- Security levels define required protective measures.
- Ships require Ship Security Plans and Ship Security Officers.
- Port facilities require matching security arrangements.
- Communication between ship, company, and port is essential.

## Watch Points

- Security is different from safety, but both affect operation.
- ISPS drills, access control, declarations of security, and restricted areas are practical points.

## Study Order

1. Learn security levels.
2. Study ship security plan roles.
3. Connect ship-port interface.
