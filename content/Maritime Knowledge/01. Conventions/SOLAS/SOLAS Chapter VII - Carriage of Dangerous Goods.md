# SOLAS Chapter VII - Carriage of Dangerous Goods

## Purpose

Chapter VII covers dangerous goods in packaged form, solid bulk form, liquid chemicals, liquefied gases, and irradiated nuclear fuel-related cargoes.

## Scope

It makes specialist codes mandatory for different dangerous cargo types.

## Core Content

- IMDG Code governs dangerous goods in packaged form.
- IMSBC Code covers solid bulk cargoes.
- IBC Code covers chemical tankers.
- IGC Code covers gas carriers.
- INF Code covers certain radioactive material shipments.

## Watch Points

- Correct classification, documentation, segregation, and emergency response are central.
- Dangerous goods mistakes often begin before loading.
- Know which code applies to which cargo form.

## Study Order

1. Start with cargo form.
2. Identify the applicable code.
3. Study documentation, segregation, and emergency response.
