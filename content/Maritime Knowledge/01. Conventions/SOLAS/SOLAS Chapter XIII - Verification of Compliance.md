# SOLAS Chapter XIII - Verification of Compliance

## Purpose

Chapter XIII makes the IMO Member State Audit Scheme mandatory.

## Scope

It verifies how States implement IMO instruments. This is a State-level compliance chapter rather than a shipboard equipment chapter.

## Core Content

- Member States are audited for implementation of IMO obligations.
- The chapter supports consistent global application of safety, security, and pollution-prevention rules.
- Audit outcomes help improve maritime administration performance.

## Watch Points

- Useful for understanding flag State and coastal State responsibility.
- Less operationally detailed for shipboard study.

## Study Order

1. Learn purpose.
2. Connect to flag State performance.
3. Understand audit concept.
