# Incidents and Lessons Learned

## Purpose

DP incident learning helps prevent repeated failures.
DP incident learning은 같은 실패가 반복되는 것을 막는다.

At induction level, the goal is to understand common patterns, not memorize every case.
Induction 수준에서는 모든 사례를 외우는 것이 아니라 공통 패턴을 이해하는 것이 목표다.

## Common Incident Patterns

- PRS jump or wrong weighting
- PRS jump 또는 잘못된 weighting
- Gyro or heading input error
- Gyro 또는 heading input error
- Thruster failure or feedback mismatch
- Thruster failure 또는 feedback mismatch
- Power blackout or poor power configuration
- Blackout 또는 나쁜 power configuration
- Operator did not understand degraded status
- Operator가 degraded status를 이해하지 못함
- ASOG/WSOG not followed
- ASOG/WSOG 미준수
- Poor communication during critical activity
- Critical activity 중 통신 부족

## Learning Questions

When reading an incident, ask:
사고사례를 읽을 때 다음을 묻는다.

- What failed first?
- 무엇이 먼저 고장났는가?
- Was the failure detected?
- 고장이 탐지되었는가?
- Did the DP system react correctly?
- DP system이 올바르게 반응했는가?
- Did the operator understand the situation?
- Operator가 상황을 이해했는가?
- Which barrier failed?
- 어떤 barrier가 실패했는가?
- What should be changed?
- 무엇을 바꿔야 하는가?
