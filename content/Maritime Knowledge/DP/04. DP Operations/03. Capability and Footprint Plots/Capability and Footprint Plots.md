# Capability and Footprint Plots

## Capability Plot

A capability plot shows the environmental limit that the vessel can theoretically withstand while maintaining position.
Capability plot은 선박이 위치를 유지할 수 있는 이론적 환경 한계를 보여준다.

It usually considers wind, current, wave, heading, thruster capacity, and vessel configuration.
보통 wind, current, wave, heading, thruster capacity, vessel configuration을 고려한다.

## Footprint Plot

A footprint plot shows how the vessel actually moved during a DP test or operation.
Footprint plot은 DP test 또는 작업 중 선박이 실제로 어떻게 움직였는지 보여준다.

It is based on measured position data.
측정된 position data를 기반으로 한다.

## Difference

| Plot | Main question |
|---|---|
| Capability plot | Can the vessel theoretically hold position in this environment? |
| Footprint plot | How well did the vessel actually hold position? |

## Why It Matters

Capability plot is a planning tool.
Capability plot은 계획 도구다.

Footprint plot is an evidence tool.
Footprint plot은 증거 도구다.

DPO should not treat either as perfect truth.
DPO는 둘 중 어느 것도 완전한 진실로 취급하면 안 된다.

## Induction-Level Watch Points

- The plot depends on vessel configuration.
- Plot은 선박 구성에 따라 달라진다.
- Thruster failure changes capability.
- Thruster failure는 capability를 바꾼다.
- Environmental direction matters.
- 환경 방향이 중요하다.
- Capability does not guarantee safe operation.
- Capability가 safe operation을 보장하지 않는다.
- Footprint must be interpreted with operation, sea state, and PRS quality.
- Footprint는 작업, sea state, PRS quality와 함께 해석해야 한다.
