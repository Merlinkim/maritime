# CAMO and TAM

## Definition

CAMO means Critical Activity Mode of Operation.
CAMO는 Critical Activity Mode of Operation을 뜻한다.

TAM means Task Appropriate Mode.
TAM은 Task Appropriate Mode를 뜻한다.

Both terms describe how the DP system should be configured for the risk level of the operation.
두 용어 모두 작업 위험도에 맞춰 DP system을 어떻게 구성해야 하는지 설명한다.

## CAMO

CAMO is used for critical operations where loss of position can cause serious consequences.
CAMO는 위치 상실이 큰 결과를 만들 수 있는 critical operation에서 사용된다.

The vessel is normally configured to withstand the defined worst-case failure.
선박은 보통 정의된 worst-case failure를 견딜 수 있도록 구성된다.

Examples:
예시:

- Diving support
- Heavy lift close to installation
- Offshore construction near subsea asset
- Gangway or personnel transfer in critical condition

## TAM

TAM is a configuration suitable for a specific task.
TAM은 특정 작업에 적합한 구성이다.

It may be less conservative than CAMO if the consequence is lower.
결과가 낮은 작업에서는 CAMO보다 덜 보수적일 수 있다.

The key question is:
핵심 질문은 다음이다.

```text
What DP configuration is appropriate for this task and its consequence?
```

## Why It Matters

DP class alone does not decide safe operation.
DP class만으로 안전 운항이 결정되지 않는다.

A DP2 vessel can still be operated in a poor configuration.
DP2 선박도 나쁜 구성으로 운용될 수 있다.

CAMO/TAM connects vessel configuration with the actual operation.
CAMO/TAM은 선박 구성을 실제 작업과 연결한다.

## DPO Checks

- Is the selected mode suitable for the task?
- 선택된 mode가 작업에 적합한가?
- Are generators, switchboards, bus-ties, and thrusters configured as required?
- 발전기, switchboard, bus-tie, thruster 구성이 요구사항과 맞는가?
- Is the configuration consistent with ASOG/WSOG?
- 구성이 ASOG/WSOG와 일치하는가?
- What is the worst-case failure in this configuration?
- 이 구성에서 worst-case failure는 무엇인가?
- After failure, is there enough capability to continue or escape?
- 고장 후 계속 작업하거나 이탈할 능력이 남는가?
