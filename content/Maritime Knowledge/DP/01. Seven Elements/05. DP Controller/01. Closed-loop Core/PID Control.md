# PID Control

## 한 줄 정의

PID Control은 오차를 줄이기 위해 제어 명령을 만드는 기본 방식이다.

DP Controller는 단순한 PID 하나로만 움직이는 것은 아니지만, 오차에 어떻게 반응하는지 이해하는 첫 단계로 좋다.

## PID의 세 부분

```text
제어 출력 = P + I + D
```

| 부분 | 보는 값 | 쉬운 의미 |
|---|---|---|
| P | 지금 오차 | 지금 많이 벗어났으면 강하게 민다 |
| I | 오차의 누적 | 계속 남는 오차를 천천히 없앤다 |
| D | 오차 변화 속도 | 너무 빠르게 움직이면 눌러준다 |

## 자동차 예시

차가 차선 오른쪽으로 벗어났다고 생각하면 된다.

- P는 “지금 오른쪽으로 얼마나 벗어났는가”를 본다
- I는 “계속 오른쪽으로 밀리고 있는가”를 본다
- D는 “너무 빠르게 오른쪽으로 가고 있는가”를 본다

DP도 비슷하게 위치 오차와 heading 오차를 줄이려고 한다.

## DP에서 의미

DP에서는 surge, sway, yaw 방향으로 오차가 생긴다.

Controller는 이 오차를 보고 필요한 힘과 moment를 만든다.

```text
위치 오차 / heading 오차
        ↓
DP Controller
        ↓
필요한 surge force / sway force / yaw moment
        ↓
Thrust Allocation
```

## Gain을 높이면 무조건 좋은가

아니다.

Gain이 높으면 선박이 빠르게 반응할 수 있지만, 너무 높으면 오히려 흔들릴 수 있다.

| 상태 | 결과 |
|---|---|
| Gain이 너무 낮음 | 복귀가 느리고 위치 오차가 커짐 |
| Gain이 너무 높음 | 오버슈트, 진동, 추진기 헌팅 가능 |
| I가 과함 | 계속 밀어붙이다가 나중에 크게 튈 수 있음 |
| D나 필터가 부적절함 | 잡음에 민감하거나 반응이 둔해질 수 있음 |

## DPO가 이해할 점

DPO가 PID를 직접 튜닝하는 것은 보통 아니다.

하지만 운용 모드나 weather/gain setting을 바꾸면 다음이 달라진다는 점은 알아야 한다.

- 위치 유지 정확도
- 추진기 움직임
- 전력 사용량
- 기계적 마모
- 선박 반응 속도

무조건 강한 설정이 좋은 것이 아니다.

작업 위험, 환경, 선박 절차에 맞게 써야 한다.

## 기억할 문장

PID는 “지금 오차, 쌓인 오차, 오차 변화 속도”를 보고 명령을 만드는 기본 개념이다.

DP에서는 이 개념 위에 선박 모델, 필터, 제한 로직이 더해진다고 보면 된다.
