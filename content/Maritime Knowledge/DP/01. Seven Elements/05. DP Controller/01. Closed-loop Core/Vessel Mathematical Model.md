# Vessel Mathematical Model

## 한 줄 정의

Vessel Mathematical Model은 DP 컴퓨터 안에 들어있는 “간단한 가상 선박”이다.

실제 선박과 완전히 같은 것은 아니고, DP가 계산에 쓸 수 있을 정도로 단순화한 선박 움직임 모델이다.

## 왜 필요한가

DP는 센서값만 보고 움직이면 안 된다.

센서값에는 잡음, 지연, 튐, 오차가 있기 때문이다.

그래서 DP는 선박 모델을 이용해 이렇게 예상한다.

```text
이전 위치가 이랬고,
추진기가 이렇게 힘을 냈고,
선박이 이런 무게와 저항을 가진다면,
지금쯤 선박은 어디에 있어야 하지?
```

이 예측값을 센서값과 비교하면 센서가 이상한지, 선박이 진짜 움직인 것인지 판단하는 데 도움이 된다.

## DP에서 주로 보는 움직임

DP가 위치 유지에서 주로 제어하는 것은 수평면 움직임이다.

| 움직임 | 쉬운 뜻 |
|---|---|
| Surge | 앞뒤 움직임 |
| Sway | 좌우 움직임 |
| Yaw | 선수 방향 회전 |

Roll, pitch, heave도 중요하지만, DP Controller가 직접 유지하려는 핵심은 보통 위치와 heading이다.

## 가장 쉬운 생각

핵심은 뉴턴 법칙과 비슷하다.

```text
힘을 주면 선박이 움직인다.
하지만 선박은 무겁고,
물의 저항을 받고,
바람과 조류의 영향을 받는다.
```

그래서 DP 모델은 대충 이런 관계를 계산한다.

```text
추진기 힘 + 환경 힘 - 저항
        ↓
선박의 속도 변화
        ↓
선박의 위치 변화
```

수식을 완벽히 외울 필요는 없다.

처음에는 “힘을 넣으면 선박이 어떻게 움직일지 예측하는 계산”이라고 이해하면 된다.

## 모델 안에 들어가는 생각들

| 요소 | 쉬운 설명 |
|---|---|
| 선박 질량 | 배가 얼마나 무거운가 |
| 관성 | 움직임이나 회전을 바꾸기 얼마나 어려운가 |
| 부가질량 | 선박이 물을 같이 밀고 움직이는 효과 |
| 감쇠 | 물의 저항 때문에 움직임이 줄어드는 효과 |
| 추진기 위치 | 각 추진기가 어디에 달려 있는가 |
| 추진기 방향 | 각 추진기가 어느 방향으로 힘을 내는가 |
| 바람 영향 | 바람이 선체에 주는 힘 |
| 조류 영향 | 물의 흐름이 선박에 주는 힘 |
| 좌표 변환 | 선박 기준 방향과 지구 기준 방향을 바꾸는 계산 |

## Closed-loop에서 위치

```text
추진기 명령
        ↓
선박 모델
        ↓
예상 위치 / 예상 속도 / 예상 heading
        ↓
Kalman Filter
        ↓
추정된 현재 상태
        ↓
DP Controller
```

선박 모델은 주로 “예측” 쪽에서 일한다.

센서가 들어오기 전에 “선박이 아마 이렇게 움직였을 것”이라고 예상하는 역할이다.

## 언제 문제가 되는가

모델은 실제 선박이 아니라 단순화된 계산이다.

그래서 현실과 차이가 생길 수 있다.

| 원인 | 결과 |
|---|---|
| 흘수나 적재상태가 변함 | 선박 반응이 예상과 달라짐 |
| 추진기 성능이 떨어짐 | 명령한 만큼 힘이 안 나옴 |
| 선체 오염이 심함 | 저항이 커짐 |
| 얕은 수심 | 선박 움직임이 달라짐 |
| 구조물 근처 작업 | 조류나 와류가 복잡해짐 |
| 갑판 적재물이 큼 | 바람 영향이 달라짐 |

## DPO가 봐야 할 것

DPO가 모델을 직접 튜닝하지는 않는다.

하지만 모델과 현실이 안 맞는 느낌은 읽을 수 있어야 한다.

- 추진기 명령은 큰데 선박 반응이 약한가
- PRS가 끊긴 뒤 추정 위치가 이상하게 흘러가는가
- 흘수나 적재상태 변화 후 DP 반응이 달라졌는가
- 같은 바람인데 예전보다 추진기 사용량이 큰가
- 추정 current가 비정상적으로 커지거나 방향이 이상한가

## 기억할 문장

Vessel Mathematical Model은 DP 안의 “가상 선박”이다.

이 모델은 센서값을 대신하는 것이 아니라, 센서값이 말이 되는지 판단하고 현재 상태를 추정하는 데 도움을 준다.
