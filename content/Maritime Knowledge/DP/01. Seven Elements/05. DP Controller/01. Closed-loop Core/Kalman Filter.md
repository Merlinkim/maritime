# Kalman Filter

## 한 줄 정의

Kalman Filter는 여러 센서값과 선박 모델을 섞어서 “지금 선박이 어디에 있을 가능성이 가장 큰가”를 계산하는 방법이다.

## 왜 필요한가

DP는 센서 하나만 보고 움직이면 위험하다.

PRS는 튈 수 있고, 자이로는 틀어질 수 있고, MRU는 보정이 틀릴 수 있다.

그래서 DP는 이런 질문을 계속 한다.

```text
센서값은 이렇게 말한다.
모델 예측은 이렇게 말한다.
둘 중 무엇을 더 믿어야 하지?
```

이 판단을 계속 반복하는 것이 Kalman Filter의 핵심이다.

## 위치

Kalman Filter는 센서와 DP Controller 사이에 있다.

```text
PRS / Gyro / MRU
        ↓
센서값 검사
        ↓
Kalman Filter
        ↓
추정된 현재 위치와 heading
        ↓
DP Controller
```

DP Controller가 보는 위치는 보통 raw PRS 값 그대로가 아니다.

필터를 거쳐 만들어진 “추정 위치”에 가깝다.

## 아주 쉬운 예시

선박이 천천히 오른쪽으로 밀리고 있다고 하자.

그런데 PRS가 갑자기 왼쪽으로 3미터 튀었다.

Kalman Filter는 대충 이런 판단을 한다.

```text
선박이 진짜 순간적으로 3미터 움직였나?
아니면 PRS가 튄 건가?

자이로와 MRU는 이상 없나?
다른 PRS도 같이 움직였나?
선박 모델상 이런 움직임이 가능한가?
```

이 결과에 따라 센서값을 많이 믿을 수도 있고, 적게 믿을 수도 있고, 아예 제외할 수도 있다.

## 기본 반복 구조

```text
1. 예측한다
   이전 상태와 선박 모델로 지금 상태를 예상한다.

2. 측정값을 받는다
   PRS, 자이로, MRU 등의 값을 받는다.

3. 비교한다
   예측값과 측정값이 얼마나 다른지 본다.

4. 믿을 정도를 정한다
   센서가 좋은지, 모델이 더 그럴듯한지 판단한다.

5. 수정한다
   가장 그럴듯한 현재 상태를 만든다.

6. 다시 반복한다
```

## DP에서 좋은 점

### 여러 센서를 하나의 상태로 묶어준다

DP는 여러 PRS와 센서를 동시에 사용한다.

Kalman Filter는 이 값들을 하나의 현재 선박 상태로 정리해준다.

### 잡음을 줄인다

센서값은 항상 조금씩 흔들린다.

그 흔들림을 DP가 그대로 따라가면 추진기가 계속 불필요하게 움직인다.

필터는 이런 짧은 잡음을 줄여준다.

### 짧은 신호 끊김을 버티게 해준다

PRS가 아주 짧게 끊겨도 선박 모델을 이용해 잠깐 예측할 수 있다.

하지만 오래 버틸 수 있다는 뜻은 아니다.

시간이 지날수록 불확실성이 커진다.

### PRS 튐을 알아차리는 데 도움을 준다

측정값이 예측값과 너무 다르면 의심할 수 있다.

이 차이가 크면 DP는 그 센서를 덜 믿거나 제외할 수 있다.

## DPO가 이해해야 할 정도

DPO가 수식을 계산할 필요는 없다.

하지만 이 정도는 알아야 한다.

- 화면의 위치값은 raw sensor value가 아닐 수 있다
- DP는 센서값과 모델 예측을 섞어서 상태를 만든다
- 센서가 튀면 바로 따라가지 않고 검증할 수 있다
- 모든 센서가 같은 방향으로 틀리면 필터도 틀릴 수 있다
- 모델이 현실과 안 맞으면 추정이 나빠질 수 있다

## 문제가 생기는 경우

| 경우 | 무슨 일이 생기나 |
|---|---|
| 모든 PRS가 같은 방향으로 틀림 | 필터가 틀린 위치를 맞다고 믿을 수 있음 |
| 선박 모델이 현실과 다름 | 예측이 계속 틀어질 수 있음 |
| 센서 지연이 큼 | 과거 값을 보고 현재를 추정할 수 있음 |
| 설정이 너무 민감함 | 잡음에도 추진기 명령이 흔들릴 수 있음 |
| 설정이 너무 둔함 | 실제 변화에 늦게 반응할 수 있음 |

## DPO가 볼 것

- PRS 품질 상태가 변했는가
- PRS 선택/해제 순간 추정 위치가 튀는가
- PRS가 끊겼을 때 추정 위치가 천천히 드리프트하는가
- 측정 위치는 흔들리는데 추진기 명령도 같이 흔들리는가
- 환경 변화 후 추정 current가 천천히 변하는가

## 기억할 문장

Kalman Filter는 “센서를 믿을지, 모델을 믿을지”를 계속 조절하는 부분이다.

DP에서 화면에 보이는 현재 위치는 “측정값”이라기보다 “추정값”에 가깝다.
