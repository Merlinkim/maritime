# MSC.1-Circ.1580 Equipment Classes

## Purpose

This section explains DP equipment classes and links them to the consequence of position loss.

## Core Points

- Equipment Class 1 has no required redundancy against a single failure.
- Equipment Class 2 should maintain position after a single fault in an active component or system.
- Equipment Class 3 should maintain position after specified single failures including fire or flooding in a compartment, subject to system design.
- Equipment class selection should match operational consequence.

## Practical DP Meaning

- Never choose class by prestige; choose it by consequence of loss of position.
- DP2/DP3 notation does not remove the need for operational limits.
- WCFDI and consequence analysis become more important as class increases.
