# DP Glossary

## Terms

| Term | Meaning |
|---|---|
| DP | Dynamic Positioning. Automatic position and heading control using thrusters. |
| DPO | Dynamic Positioning Operator. Operator responsible for DP watch and control. |
| PRS | Position Reference System. Provides vessel position reference to DP. |
| MRU | Motion Reference Unit. Measures roll, pitch, heave, and motion data. |
| Gyro | Heading reference sensor, normally true heading for DP. |
| HMI | Human-Machine Interface. DP operator display and control interface. |
| FMEA | Failure Modes and Effects Analysis. Study of failures and their effects. |
| WCFDI | Worst Case Failure Design Intent. Worst failure the vessel is designed to withstand. |
| ASOG | Activity Specific Operating Guidelines. Operation-specific decision guideline. |
| WSOG | Well Specific Operating Guidelines. Well-specific version of operating guideline. |
| CAMO | Critical Activity Mode of Operation. Configuration for critical activity. |
| TAM | Task Appropriate Mode. Configuration suitable for a task. |
| DPVAD | DP Verification Acceptance Document. DP verification/acceptance documentation. |
| Consequence Analysis | Prediction of remaining position-keeping capability after failure. |
| Capability Plot | Theoretical environmental holding capability plot. |
| Footprint Plot | Actual measured vessel movement during DP. |
| Thrust Allocation | Distribution of required force/moment to individual thrusters. |
| Feed-forward | Control action based on measured disturbance before error develops. |
| Feedback | Control action based on measured/estimated error. |
| Kalman Filter | Estimator combining model prediction and measurements. |
| Observer | Estimator that reconstructs vessel state from model and measurements. |
| Redundancy | Ability to tolerate failure without losing required function. |
| Common-mode Failure | One cause creating several failures at the same time. |
| Sensor Weighting | Trust level assigned to each sensor/reference. |
| Rejection | Excluding a bad sensor/reference from the DP estimate. |
