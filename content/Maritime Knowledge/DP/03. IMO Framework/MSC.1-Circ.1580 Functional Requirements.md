# MSC.1-Circ.1580 Functional Requirements

## Purpose

This section describes what the DP system must be able to do functionally.

## Core Points

- The system must control position and heading using available sensors, position references, power, and thrusters.
- Redundancy, independence, alarms, monitoring, and failure response must support the selected equipment class.
- Power, thruster, and control systems must be designed so failures are detected and managed.
- Essential information must be available to the operator.

## Practical DP Meaning

- Functional requirements are the bridge between design and operation.
- For DPO study, ask: what does the operator need to know before the vessel loses position?
- For FMEA, ask: what function is lost, degraded, or falsely indicated?
