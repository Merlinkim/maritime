# Thruster System (IMO)

> Note: This is a study note, not a verbatim reproduction of the source document.
> 주의: 이 페이지는 학습용 정리이며 원문 전체의 재배포본이 아니다.

Reference source: IMO MSC.1/Circ.1580 public copy via USCG — https://www.dco.uscg.mil/Portals/9/OCSNCOE/References/DP-Guidance/IMO/MSC.1-Circ.1580.pdf

## Purpose

The thruster system converts DP control demand into actual force and moment on the vessel.

## Core Points

- Includes thrusters, propulsion motors/drives, pitch/azimuth controls, local control, cooling/lube/hydraulic support, feedback, and alarms.
- Thruster availability must be understood as available force in the required direction, not only whether a unit is running.
- Thruster allocation depends on remaining thrusters, forbidden zones, efficiency, and environmental load.

## Practical DP Meaning

- A thruster can be electrically available but operationally limited.
- Azimuth feedback, pitch feedback, drive trips, ventilation/cooling, and hydraulic issues can degrade DP without obvious total failure.
- Thruster interaction and current/wind direction matter.
