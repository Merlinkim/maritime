# Three Sub-systems of DP

> Note: This page follows the IMO MSC.1/Circ.1580 system boundary in study-note form.
> 주의: 이 페이지는 IMO MSC.1/Circ.1580의 시스템 경계를 학습용으로 정리한 것이다.

Reference source: IMO MSC.1/Circ.1580 public copy via USCG — https://www.dco.uscg.mil/Portals/9/OCSNCOE/References/DP-Guidance/IMO/MSC.1-Circ.1580.pdf

IMO MSC.1/Circ.1580 divides the DP system into three sub-systems.
IMO MSC.1/Circ.1580은 DP system을 세 하위 시스템으로 구분한다.

1. [[Power System (IMO)]]
2. [[Thruster System (IMO)]]
3. [[DP Control System (IMO)]]

## System Flow

```text
Power System
     ↓ electrical power
Thruster System ← commands ← DP Control System
     ↓ force                       ↑ feedback
   Vessel ─────────────────────────┘
```

## Why This Boundary Matters

- It defines what must be considered when assessing DP capability.
- DP 능력을 평가할 때 고려해야 할 시스템 경계를 정한다.
- It supports equipment class, redundancy, WCFDI, FMEA, and proving trials.
- Equipment class, redundancy, WCFDI, FMEA, proving trial의 기준이 된다.
- It separates machine capability from the human element.
- 장비 시스템과 인간 운용 요소를 구분한다.
