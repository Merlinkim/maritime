# MSC.1-Circ.1580 General and Definitions

## Purpose

This section defines the language used in the guideline: DP vessel/unit, DP system, sub-systems, redundancy, worst-case failure, and related concepts.

## Core Points

- The DP system is divided into power, thruster, and DP control sub-systems.
- The DP control system includes computers, sensors, PRS, display/HMI, networks, and cabling needed for DP control.
- Redundancy and single-failure tolerance are central concepts.
- The definitions create the boundary used later for equipment classes and FMEA.

## Practical DP Meaning

- Learn these definitions before FMEA.
- If the system boundary is unclear, failure analysis becomes confused.
- The Three Sub-systems page should be read with this section.
