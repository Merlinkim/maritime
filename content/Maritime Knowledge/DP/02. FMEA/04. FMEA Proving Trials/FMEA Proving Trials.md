## Purpose

This page explains how proving trials validate the FMEA.

## Core Points

- Trials should demonstrate that predicted failure effects and safeguards match real vessel behavior.
- Tests should cover power, thrusters, controls, sensors, PRS, networks, and key auxiliaries.
- Results should record expected outcome, actual outcome, alarms, operator indications, and corrective actions.
- Unsuccessful or surprising results should feed back into the FMEA.

## Practical DP Meaning

- A proving trial is not a show; it is an engineering test.
- Do not only test easy failures.
- Evidence quality matters: configuration, conditions, screenshots/logs, and sign-off should be traceable.
